### The setup

- **OS** — NixOS · flake-based, entire system is one file
- **WM** — Hyprland · borders animate as liquid blue→purple→cyan gradient *(Lua config)*
- **Shell** — Nushell · vi mode · SQLite history · 100k entries
- **Editor** — Neovim via NvChad
- **Term** — Kitty · custom Python tab bar with git status + clock
- **Theme** — Tokyo Night across every surface

> Change wallpaper → Hyprland borders + Kitty colors resync live

<br clear="right"/>

---

### Things I built into the rice

| Tool | What it does |
|------|-------------|
| **WallRizz** | wallpaper change → full color resync, random animation |
| **Kitty tab bar** | live dir · git branch · staged/modified/untracked · clock |
| **VPN TUI** | waybar click → fzf menu: connect, import `.pcf`/`.ovpn`, edit in nvim |
| **GPU passthrough hook** | QEMU hook auto-detaches GPU from host on VM start, re-attaches on stop |
| **Cheatsheet** | `Super+C` → fzf browser over 139 shortcuts (Hyprland · Nushell · Neovim · Yazi · Git) |
| **Eye care timer** | 20-20-20 rule · countdown in waybar · race-condition safe |
| **NixOS panel** | rebuild switch · update flake · GC · view generations — from waybar |
| **doller** | custom symlink installer with TUI, conflict backup, dry-run |
