### Setup

I run NixOS with Hyprland and Tokyo Night across every surface. The dotfiles are a project in themselves — animated liquid borders in Lua, a custom Python tab bar in Kitty, live wallpaper→color sync, a VPN TUI, GPU passthrough hooks, and a fzf cheatsheet browser over 139 keybinds. Entire system is declarative and reproducible from one flake.
